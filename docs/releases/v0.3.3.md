CrabPDF 0.3.3 es una **versión preliminar** para Windows y Linux x86_64. Todavía no alcanza la paridad 1.0 con SumatraPDF.

- **Windows 10/11:** ZIP portable x64 o x86. La entrega corrige la pantalla completa para aprovechar el área de lectura y las flechas izquierda/derecha en el visor. Se verificó en Windows 10 x64 y como proceso x86 bajo WOW64; Windows 11 y un SO Windows de 32 bits requieren pruebas propias.
- **Ubuntu 24.04:** instalar el `.deb` con `sudo apt install ./crabpdf-0.3.3-ubuntu24.04-amd64.deb`. Incluye PDFium, MuPDF 1.28.5 y libmobi 0.12; APT instala DjVuLibre, 7-Zip y bibliotecas de escritorio. Mint 22 puede instalarlo si resuelve esas dependencias, pero todavía no se ha probado.
- **Otros Linux x86_64:** el `.tar.gz` incluye el lector y las mismas bibliotecas principales. Leer `INSTALL-LINUX.md` para las dependencias del sistema. Se compiló sobre glibc 2.36 y se probó en Ubuntu 24.04 con Xvfb; otras distribuciones y Wayland siguen pendientes.

Windows superó las 17 comprobaciones locales documentadas. En Ubuntu 24.04, las siete pruebas nativas de formatos/marcas y el recorrido gráfico de 25 capturas terminaron correctamente; el tar y el `.deb` verificaron 408 archivos cada uno. Los registros y límites están en `docs/IMPLEMENTATION_PROGRESS_0_3_3.md` y `docs/IMPLEMENTATION_PROGRESS_0_3_3_LINUX.md` del repositorio.

`crabpdf-0.2.0-format-tools-sources.zip` contiene las fuentes de los conversores utilizadas desde 0.2.0, incluidas MuPDF/libmobi; se conserva ese nombre para no atribuirles un cambio inexistente. `SHA256SUMS-v0.3.3.txt` permite verificar los archivos descargados. No hay firma digital. Faltan impresión, edición general de PDF, accesibilidad completa y otras funciones de la meta 1.0.
