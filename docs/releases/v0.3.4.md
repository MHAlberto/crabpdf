CrabPDF 0.3.4 es una **versión preliminar** hacia la paridad 1.0 con SumatraPDF.

- Recupera el punto relativo de lectura al reabrir un documento, incluso con otra ventana o escala lógica. También guarda el modo manga y conserva la compatibilidad con las preferencias antiguas.
- Espera la geometría real de las páginas largas antes de restaurar el punto. Los parámetros explícitos de la CLI y la navegación del usuario prevalecen sobre el estado guardado.
- Mantiene lectura continua, pantalla completa con controles flotantes y resaltado/subrayado de la versión anterior.

Descargas:

- **Windows:** ZIP portable x64 o x86. Se verificaron ambas arquitecturas en Windows 10 x64; x86 bajo WOW64. Windows 11 y un SO Windows de 32 bits requieren pruebas propias.
- **Ubuntu 24.04:** `sudo apt install ./crabpdf-0.3.4-ubuntu24.04-amd64.deb`. Incluye PDFium, MuPDF 1.28.5 y libmobi 0.12; APT instala DjVuLibre, 7-Zip y bibliotecas de escritorio.
- **Linux x86_64:** tar con el mismo lector y herramientas principales, compilado sobre glibc 2.36. Leer `INSTALL-LINUX.md` para las dependencias. Las demás distribuciones y Wayland siguen pendientes.

Windows pasó **19 comprobaciones** y produjo 90 capturas por arquitectura. Ubuntu 24.04 limpio pasó las pruebas nativas, el recorrido de 25 capturas y la reapertura entre tres procesos con otras tres capturas. Se verificaron 607 archivos por ZIP y 408 por paquete Linux. La [CI del código](https://github.com/MHAlberto/crabpdf/actions/runs/38785344688) pasó los cinco targets, incluidos macOS Intel/ARM; en macOS todavía faltan interfaz, otros formatos y paquete `.app`. [Informe y límites](https://github.com/MHAlberto/crabpdf/blob/v0.3.4/docs/IMPLEMENTATION_PROGRESS_0_3_4.md).

`SHA256SUMS-v0.3.4.txt` permite verificar las descargas. `crabpdf-0.2.0-format-tools-sources.zip` conserva las fuentes de conversores utilizadas, sin atribuirles un cambio de versión inexistente.

El historial completo persistente y las sesiones concurrentes del mismo archivo siguen pendientes. El ancla es geométrica y no detecta cambios de contenido/paginación. También faltan impresión, edición general de PDF, accesibilidad completa y otras funciones de la meta 1.0. No hay firma digital ni se certifican todas las plataformas por una compilación correcta.
