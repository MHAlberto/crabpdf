CrabPDF 0.4.0 consolida las mejoras de lectura y añade el instalador nativo de Windows. Es una versión de desarrollo hacia 1.0.

- Instalador EXE x64/x86 con el logo de CrabPDF, asistente nativo, instalación por usuario y desinstalador. Conserva preferencias, marcas y archivos ajenos.
- Marcar, subrayar y deshacer conserva la página visible mientras se actualiza el render. Se estabiliza el zoom durante esa actualización.
- Desplazamiento continuo al mantener las flechas y selección de texto con menos trabajo repetido.
- Arrastrar una pestaña fuera abre otra ventana, conservando página, zoom, colores y punto de lectura.
- Favoritos del libro activo, pantalla completa sin pie inferior, controles y transiciones refinados.
- Migración modular de favoritos, pestañas, perfiles, búsqueda/selección, protocolo del worker y planificador. Se conservan las cachés y el único propietario de PDFium.
- Corrección de la preparación de PDFium x86 en CI y descargas verificadas con reintentos limitados.

Descargas:

- **Windows x64:** `crabpdf-0.4.0-win-x64-setup.exe`, o ZIP portable.
- **Windows x86:** `crabpdf-0.4.0-win-x86-setup.exe`, o ZIP portable.
- **Ubuntu 24.04 x64:** `sudo apt install ./crabpdf-0.4.0-ubuntu24.04-amd64.deb`.
- **Linux x86_64:** tar para una base glibc 2.36 o posterior, con los requisitos indicados en `INSTALL-LINUX.md`.

**Los instaladores y paquetes están sin firma digital.** Todavía no disponemos de certificado; Windows puede mostrar advertencias. No se afirma una certificación independiente de seguridad.

La aplicación no necesita cuentas ni conexión para leer. PDFium y las herramientas de formatos se incluyen o se declaran como dependencias del sistema. Los ZIP Windows deben conservar `pdfium.dll` y `format-tools/`.

`SHA256SUMS-v0.4.0.txt` permite comprobar los paquetes. `crabpdf-0.4.0-format-tools-sources.zip` contiene las fuentes originales de los conversores y los scripts de compilación Windows/Linux.

Windows x86 se comprueba bajo WOW64. La validación Ubuntu usa un escritorio virtual; Windows 11, Windows de 32 bits nativo, Wayland y otras distribuciones necesitan evidencia propia. La CI también compila y prueba macOS Intel/ARM, pero esta entrega no incluye un paquete macOS.

La paridad completa con SumatraPDF sigue pendiente: impresión, formularios/edición general de anotaciones, SyncTeX y accesibilidad, entre otras rutas.
