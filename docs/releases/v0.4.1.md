CrabPDF 0.4.1 corrige la barra de pestañas y reduce trabajo repetido en la interfaz. Es una versión de desarrollo hacia 1.0.

- Inicio, abrir, pestañas y botones de ventana comparten la misma línea central.
- Arrastrar el espacio libre de la barra mueve la ventana. Arrastrar una pestaña conserva su comportamiento de abrir otra ventana.
- El título nativo sólo se construye cuando cambia el documento o se vuelve a Inicio; la ruta completa de cada pestaña se prepara al mostrar su ayuda.
- Las portadas PNG se codifican desde el buffer existente, evitando una copia completa de sus píxeles.
- F6 invierte/restaura los colores del documento; Mayús+I sigue disponible. La inversión es de lectura y no altera el archivo original.
- Se incluye la reorganización del código en core, application, runtime y desktop realizada después de la publicación 0.4.0.

Descargas:

- **Windows x64:** `crabpdf-0.4.1-win-x64-setup.exe` o ZIP portable.
- **Windows x86:** `crabpdf-0.4.1-win-x86-setup.exe` o ZIP portable.
- **Ubuntu 24.04 x64:** `sudo apt install ./crabpdf-0.4.1-ubuntu24.04-amd64.deb`.
- **Linux x64:** TAR para glibc 2.36 o posterior; consulta sus requisitos en `INSTALL-LINUX.md`.

La etiqueta `v0.4.1` apunta a `6eb980a269809280668b1b2007b9ff5e36f52fda`, validado en las cinco plataformas por [GitHub Actions](https://github.com/MHAlberto/crabpdf/actions/runs/40565789343). Los instaladores y ZIP Windows proceden de los artefactos de esa ejecución e incluyen las comprobaciones de instalación, actualización y desinstalación. Los paquetes Linux se compilan con el mismo código de aplicación sobre Debian Bookworm y se comprueban en Ubuntu 24.04 dentro de Docker.

**Los instaladores y paquetes siguen sin firma digital.** No disponemos de certificado de firma y no se afirma una certificación independiente de seguridad. El logo y el asistente nativo se conservan. Windows puede mostrar advertencias al abrir el instalador.

`SHA256SUMS-v0.4.1.txt` permite verificar la descarga. El ZIP `crabpdf-0.4.1-format-tools-sources.zip` contiene las fuentes y scripts correspondientes a los conversores incluidos. Conserva PDFium y las herramientas junto al ejecutable cuando uses el ZIP o TAR.
