# CrabPDF 0.4.4

Entrega de desarrollo para Windows x64/x86 y Ubuntu/Linux x64.

## Cambios

- En lectura continua puedes arrastrar una selección entre páginas en ambos sentidos. Mantén el puntero cerca del borde del visor para seguir desplazándote. Ctrl+C / ⌘C copia el texto en orden de página. Se respetan los permisos de copia del documento.
- **Ayuda → Buscar actualizaciones…** consulta GitHub y verifica el tamaño y SHA-256 del paquete antes de instalarlo. En Windows actualiza la carpeta de instalación y conserva el perfil y los accesos configurados. En Ubuntu, el paquete DEB se actualiza con apt y autorización del sistema. Las ediciones portables ofrecen el enlace al archivo correspondiente.
- El visor reutiliza la geometría de selección de las páginas visibles y prepara por páginas el texto que va al portapapeles.

## Descargas

Windows dispone de instalador EXE y ZIP portable para x64 y x86. Para Ubuntu 24.04 x64 está el DEB. El TAR.GZ de Linux x64 requiere glibc 2.36 o posterior y conserva sus instrucciones dentro del paquete.

Los instaladores Windows están **sin firma digital**. Los hashes SHA-256 de todos los archivos se publican junto a las descargas. macOS participa en la CI de compilación y motor PDF, y queda fuera de los instaladores de esta entrega.

[Descargas y comprobaciones SHA-256](https://github.com/MHAlberto/crabpdf/releases/tag/v0.4.4).

## Validación

La [CI de la etiqueta](https://github.com/MHAlberto/crabpdf/actions/runs/43248754570) pasó en Windows x64/x86, Ubuntu x64 y macOS Intel/ARM. Los dos instaladores de Windows pasaron las pruebas de instalación, actualización y desinstalación. Los recorridos gráficos release locales de Windows x64 y x86 verificaron la selección hasta la página seis y el texto enviado al portapapeles.

El [workflow de paquetes Linux](https://github.com/MHAlberto/crabpdf/actions/runs/43248755067) construyó sobre glibc 2.36 y comprobó el DEB instalado en Ubuntu 24.04 limpio con PDF, EPUB, DjVu y CBZ en Xvfb/Mesa.
