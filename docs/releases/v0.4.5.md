# CrabPDF 0.4.5

Entrega de desarrollo para Windows x64/x86 y Ubuntu/Linux x64.

- **Dos páginas** muestra el PDF lado a lado desde la barra en ventana y los controles flotantes de pantalla completa. El botón vuelve a una página con otro clic. En pantalla completa, mueve el puntero al borde superior. También puedes usar Ctrl+7 y Ctrl+6.
- El visor acota la búsqueda de páginas a las filas cercanas al área visible. La preparación del diseño y de las páginas pequeñas reduce asignaciones de memoria durante la lectura. La precarga de las páginas vecinas sigue activa.
- Los botones de navegación anterior y siguiente tienen en cuenta el par visible.

Los instaladores de Windows están **sin firma digital**. macOS participa en las compilaciones y pruebas del motor PDF, y esta entrega publica instaladores para Windows y paquetes para Ubuntu/Linux.

[Descargas y SHA-256 de la entrega](https://github.com/MHAlberto/crabpdf/releases/tag/v0.4.5).
