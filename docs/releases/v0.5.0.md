# CrabPDF 0.5.0 en desarrollo

La primera etapa incorpora el entorno de extensiones independientes en Rust.

- Administrador para instalar desde carpeta, activar una versión, desactivar y retirar paquetes.
- SDK Rust con API 1 y manifiesto de comandos, plataforma y compatibilidad de host.
- Captura de un área del PDF como imagen y texto, incluida la selección sobre documentos escaneados.
- Comandos de extensión ejecutados en segundo plano, con cancelación, límite de tiempo y respuesta de texto o LaTeX editable y copiable.
- Ejemplo Rust que comprueba la imagen y el texto recibidos.

El paquete OCR de ecuaciones a LaTeX se desarrollará sobre esta API. La primera implementación admite paquetes nativos locales con permisos de la cuenta de usuario. El [contrato de extensiones](../EXTENSIONS.md) documenta la estructura y los límites.

La [validación local](v0.5.0-validation.json) conserva los comandos, los resultados y el alcance de la primera implementación.
