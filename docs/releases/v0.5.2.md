# CrabPDF 0.5.2

CrabPDF integra el catálogo de extensiones de su página web. Copia el código de seis cifras de una extensión y búscalo en **Extensiones → Instalar por código**. La aplicación comprueba la compatibilidad, el tamaño y el SHA-256 antes de instalar. Después puedes activar la extensión.

El código **100001** corresponde a **Información de la selección**, un ejemplo que describe el recorte y el texto del PDF. El lector conserva la instalación local por carpeta y el protocolo de ejecución API 1. El SDK Rust 0.2.0 añade los tipos públicos del catálogo. OCR de ecuaciones a LaTeX sigue previsto como paquete opcional.

Los instaladores Windows de esta versión de desarrollo se distribuyen sin firma digital. Consulta [el catálogo web](https://mhalberto.github.io/crabpdf/#extensiones) y la [guía para publicar extensiones](../EXTENSIONS.md).
