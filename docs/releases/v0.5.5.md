# CrabPDF 0.5.5

El gestor separa las extensiones instaladas y el catálogo. Puedes revisar las actualizaciones disponibles, confirmar la descarga y abrir cada extensión activa desde su propio menú. Los atajos para abrir y cerrar se guardan en el perfil.

- **100002 · OCR de ecuaciones.** Descarga 179 MB de pesos ONNX y reconoce un recorte de una ecuación en el equipo. Devuelve LaTeX para copiar. Hay paquetes para Windows x64 y Linux x64.
- **100003 · Pomodoro.** Muestra un reloj sobre el PDF con sesiones de 25 minutos, descansos de 5 minutos y un aviso al terminar. El reloj sigue en marcha al cerrar su ventana.
- **100001 · Información de la selección.** Los ZIP del catálogo llevan su hash en el nombre para distinguir las descargas. Los avisos de incompatibilidad muestran las versiones o plataformas que difieren.

La web ofrece las descargas, las extensiones, la documentación y el historial en páginas separadas. La portada selecciona la plataforma cuando el navegador puede identificarla.

Los instaladores Windows de desarrollo se distribuyen sin firma digital. [Guía de extensiones](https://github.com/MHAlberto/crabpdf/blob/main/docs/EXTENSIONS.md).
