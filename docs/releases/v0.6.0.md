# CrabPDF 0.6.0

Al recuperar una sesión, el lector abre el PDF activo y carga cada pestaña restante cuando la seleccionas. También carga el índice de cada documento bajo demanda. Al abrir el panel de índice, el trabajador de PDFium obtiene las entradas y la interfaz dibuja las filas visibles. El gestor de extensiones permanece inactivo al iniciar con un perfil sin paquetes.

- Los paquetes del catálogo **100001**, **100002** y **100003** admiten CrabPDF 0.6.0 mediante la misma API de extensiones. El OCR de ecuaciones conserva su motor Python y sus pesos locales como descarga opcional.
- Las operaciones de actualización preservan archivos y controles de inicio de la instalación. El asistente de Windows confirma el reemplazo por etapas mediante una herramienta Rust y recupera una copia anterior si la instalación se interrumpe.
- Las extensiones conservan sus datos al reinstalarse. El gestor verifica las descargas y detecta rutas, paquetes y manifiestos inválidos.
- Las pruebas nativas cubren índice diferido, persistencia de pestañas, selección, PDFium y paquetes de extensión. La prueba de carga de PDFs grandes se puede repetir con el ejemplo Rust workload_probe.
