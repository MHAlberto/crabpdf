# CrabPDF 0.7.0

Nuevo gestor de extensiones con biblioteca, fichas de instalación y herramientas sobre el PDF.

## Extensiones

- El gestor separa la biblioteca instalada del catálogo. La biblioteca muestra la versión y el estado de cada paquete, con acciones para la extensión seleccionada.
- La consulta por código muestra la versión, el tamaño de la descarga y el aviso de confianza antes de instalar. Un paquete recién instalado queda listo para revisar y activar. Puedes consultar actualizaciones y decidir cuándo activar la versión nueva.
- El OCR, Pomodoro y las demás herramientas activas se abren sobre el PDF y tienen atajos propios. Pomodoro muestra el progreso de la sesión. El OCR sigue siendo un paquete local opcional.
- Versiones del catálogo para CrabPDF 0.7.0: Información de la selección 0.1.3, OCR de ecuaciones 0.1.4 y Pomodoro 0.1.2. El protocolo de ejecución conserva la API 1.

## Lector y actualizaciones

- La sesión recuerda la pestaña activa y difiere la apertura de las demás. Perfiles anteriores conservan el criterio anterior hasta guardar una sesión.
- Preparar un recorte para una extensión comprueba el permiso de copia directamente. Los comandos de texto evitan clonar la imagen.
- El actualizador de macOS puede ofrecer el DMG para Intel o Apple Silicon. La instalación se realiza desde el paquete descargado.
- La comprobación del instalador en CI verifica una actualización desde el instalador público 0.6.0 de cada arquitectura Windows.

Los instaladores de Windows sin firma pueden mostrar un aviso del sistema. Los DMG generados por el flujo actual de macOS carecen de notarización.
