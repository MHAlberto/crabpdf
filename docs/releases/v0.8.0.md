# CrabPDF 0.8.0 en desarrollo

Cuaderno local con citas y fórmulas, recuperación de marcas para PDFs idénticos, colecciones de lectura y diálogo de impresión.

- Guarda una cita, nota de página o resultado de OCR con una referencia al PDF. Busca tus entradas, vuelve al pasaje y exporta Markdown.
- Recupera notas al mover o renombrar el mismo PDF. Las marcas registradas también se pueden recuperar de forma explícita. Puedes cambiar su color o eliminar una marca local desde el cuaderno.
- Las colecciones guardan grupos de pestañas y posiciones. Conservan la apertura diferida.
- La impresión admite rangos y usa el servicio de Windows o CUPS. La preparación comprueba permisos PDF.
- El SDK admite un backend WASI opcional. El OCR de texto es un paquete local separado. El lector conserva un perfil de compilación con AccessKit.
- GitHub Pages admite desplegar el catálogo sin incorporar otra copia de los ZIP alojados en Releases.

El estado de publicación del lector y la evidencia de la versión pública siguen en el [registro de 0.7.0](v0.7.0-publication.json).
