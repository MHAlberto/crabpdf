# CrabPDF 0.8.1

Herramientas integradas junto al PDF, Pomodoro en la barra de lectura y dos extensiones opcionales para seguir la lectura.

- El panel lateral redimensionable reúne los controles, los comandos, los resultados y los atajos de las extensiones activas. Al recortar un área, Enter ejecuta el comando enfocado.
- Pomodoro muestra el tiempo restante en la barra. Desde el panel puedes iniciar, pausar, continuar y reiniciar la fase.
- **Estadísticas de lectura** consulta visitas a páginas, tiempo con un documento en primer plano y enfoques completados con Pomodoro. Los totales se guardan en el perfil local.
- **Guía de lectura** añade una franja de altura y posición ajustables en el visor. La guía puede seguir visible mientras usas otra extensión.
- El SDK Rust 0.5 incorpora paneles declarativos con la API de ejecución 1.

Los instaladores de Windows carecen de firma digital. Los paquetes macOS tienen firma ad hoc y se distribuyen sin notarización.
