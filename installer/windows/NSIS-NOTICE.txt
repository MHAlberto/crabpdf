Modern UI 2 / System / nsDialogs components. Copyright (C) 1999-2026 NSIS
Contributors. Original terms are reproduced in NSIS-COPYING.txt.

NSIS is separate from CrabPDF's Rust application. NSIS code and plugins use
the zlib/libpng license; its LZMA compression module uses CPL 1.0 with the
linking exception stated in NSIS-COPYING.txt. No NSIS source was modified.
